# Getting help

- **Questions and ideas:** use [GitHub Discussions](https://github.com/TurjoAt/agentneuron/discussions).
- **Bugs:** open a [bug report](https://github.com/TurjoAt/agentneuron/issues/new?template=bug_report.yml). Include `agentneuron --version`, Node version and OS.
- **Missing AI tool support:** file an [AI tool support request](https://github.com/TurjoAt/agentneuron/issues/new?template=ai_tool_support.yml).
- **Security issues:** never in public, see [SECURITY.md](SECURITY.md).
- **Documentation:** start with the [README](README.md).
- **Anything else:** hi@turjo.me (best effort; this is a community-supported open-source project).
